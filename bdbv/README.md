# Bundibugyo virus assets

This directory contains Bundibugyo virus reference assets for Pathoplexus.

The files are generated from the 2026-05-15 BDBV Nextclade dataset release.
Run
`scripts/generate_bdbv_reference_assets.py` to verify the checked-in files
match the generated assets byte-for-byte, or run it with `--write` to
regenerate them.
